# Real ruleset from calico issue #13263 (ip filter/mangle/nat), in nft command form.
# nixos-fw is the host firewall, ts-* Tailscale, KUBE-* kubelet, CNI-* the portmap plugin.
# The fib and pkttype matches are what iptables-nft-save chokes on.
# Base chains are left out: iptables has already created them.
