#### Bug fixes

- Fixes IPAM garbage collection treating an allocation as stale just because its node did not match. [calico 14591](https://github.com/projectcalico/calico/pull/14591) (@caseydavenport)
- Fixes repeated kube-controllers status updates and resulting calicoctl patch conflicts when no environment overrides are configured. [calico 14591](https://github.com/projectcalico/calico/pull/14591) (@caseydavenport)
- Fix CEL cost budget rejection for the bgppeers CRD peerIP validation rule under cel-go v0.33.1 [calico 14576](https://github.com/projectcalico/calico/pull/14576) (@kishen-v)
- Fixes a Felix panic when a malformed (empty) member is present in a NetworkSet used by the nftables dataplane; the member is now ignored with a warning. [calico 14559](https://github.com/projectcalico/calico/pull/14559) (@caseydavenport)
- CI: fix e2e lanes on release-v3.33 that failed before running tests (kind pull secret, flannel migration modprobe, rancher version keyword, EKS pod CIDR overlap, stale RHEL 8 AMI). [calico 14533](https://github.com/projectcalico/calico/pull/14533) (@lwr20)
- Fix Felix never reporting dataplane in-sync when a workload interface was deleted during its first resync after startup, which made new pods on the node wait out the full CNI policy_setup_timeout_seconds. [calico 14514](https://github.com/projectcalico/calico/pull/14514) (@fasaxc)
- Fixed a stored policy with a descending port range (for example 9000:8000) blocking the sync of every policy of that type; Felix now ignores only the invalid policy. Fix leaked QoS bandwidth IFB devices (`bwcali*`) when a pod is deleted while calico-node is restarting, and fix egress bandwidth limits not being enforced for a pod that reuses a leaked device. [calico 14485](https://github.com/projectcalico/calico/pull/14485) (@marvin-tigera)
- Fixes Goldmane counting a node's flow statistics twice when Felix reconnects to it. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- Fixes `calicoctl node status` failing to find the Felix process, which was renamed in v3.33. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- Fixes the IPAM garbage collector never releasing IPs left behind by a pod's earlier sandboxes while the pod has not yet reported an IP, which could exhaust small IP pools such as those used by Multus secondary networks. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- The IPAM garbage collector now releases leaked IPs of any pod in the Succeeded or Failed phase, not only of evicted pods. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- Fixes calico-node not assigning or releasing a node's IPIP, VXLAN, or WireGuard tunnel address when an IP pool's nodeSelector changes, which previously needed a calico-node restart. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- Fixes IP pool deletion hanging until calico-node restarts when a node's IPIP, VXLAN, or WireGuard tunnel address is in the pool. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- Fixes a leaked IP address, and an IPAM block that could never be released, when a KubeVirt VM is deleted while it is stopped. [calico 14483](https://github.com/projectcalico/calico/pull/14483) (@caseydavenport)
- eBPF: flows that must pass through the host network stack (third-party CNI egress, host-endpoint forwarding, NAT-outgoing without SNAT) no longer lose their packet mark once both directions are approved, so netfilter rules that match on it keep applying. eBPF dataplane: fix replies of asymmetrically-routed flows being sent unencapsulated out of the request's arrival interface when the reply route points at an overlay tunnel device. Fix that return traffic bypassed the tunnel in BPFOverlayHostSourceIP=HostAddress mode, exposing it to fabric path filtering.  Return traffic is now forced down the tunnel. [calico 14460](https://github.com/projectcalico/calico/pull/14460) (@tomastigera)
- By default, skip Submariner's vx-submariner interfaces in IP auto-detection. [calico 14422](https://github.com/projectcalico/calico/pull/14422) (@caseydavenport)
- Fixes an issue where a pod could lose its IP address to another pod after the container runtime retried sandbox creation and left a stale CNI ADD running, including under Multus. [calico 14422](https://github.com/projectcalico/calico/pull/14422) (@caseydavenport)
- eBPF: conntrack map autoscaling (DoubleIfFull) now doubles only the IP family whose map is more than 80% full. Grown sizes are recorded per family in /var/lib/calico/bpf_ct4_map_size and bpf_ct6_map_size. [calico 14409](https://github.com/projectcalico/calico/pull/14409) (@tomastigera)
- Felix copies BPF maps faster when it resizes them, such as when the eBPF conntrack table grows. [calico 14409](https://github.com/projectcalico/calico/pull/14409) (@tomastigera)
- eBPF conntrack metrics now carry an ip_version label, so IPv4 and IPv6 no longer overwrite each other on dual-stack nodes. New felix_bpf_conntrack_max_entries metric reports the conntrack table capacity. felix_bpf_conntrack_cleaned_total now counts cleaned entries instead of visited ones, and a failing BPF conntrack cleaner no longer crashes the conntrack scanner. [calico 14409](https://github.com/projectcalico/calico/pull/14409) (@tomastigera)
- Fixed calico-node restarts in eBPF mode resizing BPF maps to their defaults and back, which could crash the init container when the conntrack table held more entries than the default size. [calico 14409](https://github.com/projectcalico/calico/pull/14409) (@tomastigera)
- Fixed node-to-node mesh BGP sessions failing to establish from a node with its own AS number to a peer node that uses the global AS number. [calico 14368](https://github.com/projectcalico/calico/pull/14368) (@nelljerram)
- eBPF: fixed a policy program that the kernel verifier rejected with "unreachable insn" when a workload had enough policy rules to need more than one program. The node no longer reports not ready because of it. [calico 14354](https://github.com/projectcalico/calico/pull/14354) (@tomastigera)
- Fixed the tigera-operator Helm chart leaving behind a stale uninstall Job after an interrupted or failed uninstall, which blocked later uninstalls. [calico 14231](https://github.com/projectcalico/calico/pull/14231) (@rene-dekker)
- Application layer policy: the Istio sidecar injection manifests now run Dikastes from the calico image for this release instead of the retired dikastes image. [calico 14221](https://github.com/projectcalico/calico/pull/14221) (@caseydavenport)

- Fix Felix restarting with "BUG: Unexpected action" when a newly applied policy with a Pass rule changed the policy match for an active flow while flow logs were sent to Goldmane. [calico 14210](https://github.com/projectcalico/calico/pull/14210) (@fasaxc)
- Fixes policy name migration in calico-kube-controllers never running on clusters installed from the canal manifests. [calico 14207](https://github.com/projectcalico/calico/pull/14207) (@caseydavenport)
